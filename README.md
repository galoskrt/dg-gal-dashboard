# דשבורד הלידים · דיוק דיגיטלי

עמוד סטטי אחד על GitHub Pages ב-`dash.dg-gal.online`. **אין כאן שרת שנרדם
ואין קובץ נתונים שפורסם.** הלידים מגיעים מ-`dg-gal-funnel` בלבד, מאחורי אימות.

## בנייה

```
cd tools && python build.py
```

משתיל את הגופן המכווץ ואת המלח, ומייצר `index.html` בשורש. **עורכים ב-src,
לא בשורש.**

## אבטחה

הסיסמה נגזרת בדפדפן ב-PBKDF2, 600 אלף סבבים, מלח אקראי, **והתוצאה עצמה היא
המפתח שהוורקר מכיר.** בקוד המקור אין שום סוד, ולכן קריאה שלו לא נותנת כלום.
המלח אינו סוד ולכן הוא בקוד.

**החלפת סיסמה:** גוזרים ערך חדש ומגדירים אותו כ-`DASH_TOKEN` בוורקר.
